# Quazi for Sublime Text

Copy this directory to Sublime Text's `Packages/Quazi` directory and install
the `LSP` package through Package Control. The configuration starts `qz lsp`
for `.qz` buffers; replace `qz` with an absolute executable path if needed.

See the canonical [LSP contract](https://github.com/quazilang/quazistrap/blob/main/docs/tooling/lsp.md) for the
supported language features and limitations.
